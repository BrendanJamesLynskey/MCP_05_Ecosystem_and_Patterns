# MCP Ecosystem & Patterns

Field guide to the MCP ecosystem in 2026 — every host that speaks MCP, the official reference servers, the Registry, the four canonical server-design patterns (data, tools, agents, multi-server orchestration), and how distribution actually works (`uvx` / `npx` / Docker).

Updated for revision `2026-07-28`: Sampling-driven agent servers and Roots are tagged (both deprecated), and version pinning covers `server/discover` and per-request versions.
